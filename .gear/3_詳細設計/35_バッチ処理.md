# バッチ処理

WinAuth はデスクトップ常駐型クライアントアプリケーションであるため、サーバーサイドの夜間バッチは存在しませんが、アプリ内部で動作する**定期タイマージョブ・バックグラウンドポーリング処理・遅延処理・コマンドライン（CLI）起動処理**を本仕様書にて定義します。

## 2. 各ジョブ詳細仕様

### BT-001 メイン周期更新・遅延保存タイマー（`mainTimer`）
- **目的**: TOTP の残り有効時間表示のリアルタイム更新、30秒（または指定 `Period`）境界でのコード再計算・自動コピー、および連続変更時のディスク I/O 集約を行う。
- **処理手順**:
  1. 1秒ごとに `authenticatorList` を走査し、`AutoRefresh == true` の認証器について残り秒数インジケーターを更新する。
  2. タイムステップ境界（`ServerTime % (Period * 1000) < 1000`）に達した項目のコードを再計算し、`CopyOnCode == true` の場合はクリップボードへコピーする。
  3. 個別パスワード一時解除中（表示タイムアウト経過後）の項目があれば再度ロック状態へ戻す。
  4. `_saveConfigTime` が設定されており現在時刻を過ぎている場合、`WinAuthHelper.SaveConfig` を呼び出してアトミック保存を実行し、`_saveConfigTime = null` にリセットする。

### BT-002 サーバー時刻差分同期ジョブ（`Sync`）
- **目的**: 端末ローカル時計のズレを測定して `ServerTimeDiff` を補正し、TOTP 不一致を防ぐ。
- **処理手順**:
  1. シークレットが個別暗号化ロック中の場合は `EncryptedSecretDataException` を送出して中断する。
  2. 前回通信失敗時刻 `_lastSyncError` から抑止時間（`Google`/`Battle.net`: 5分、`Steam`/`Trion`: 60分）未満の場合は通信をスキップする。
  3. 各プロバイダの HTTPS 時刻エンドポイントへ接続（タイムアウト 5,000ms）し、UTC サーバー時刻を取得する。
  4. `serverTimeDiff = serverTimeMs - CurrentTime` を算出し、`|serverTimeDiff| > 86,400,000`（24時間超）の場合は異常クロックドリフトとして破棄・例外送出する。
  5. 正常範囲であれば `ServerTimeDiff` と `LastServerTime` を更新し、`_lastSyncError` をクリアする。

### BT-003 Steam トレード確認自動ポーリング（`ConfirmationPoller`）
- **目的**: トレード確認画面を閉じて常駐している間も、バックグラウンドで新規トレード確認を検知し通知または自動承認する。
- **異常時・排他制御**: 通信エラー時は最大 `DEFAULT_CONFIRMATIONPOLLER_RETRIES`（3回）リトライし、セッション切れ時は `Refresh()` で WGToken を再取得する。連続承認時は API 負荷軽減のため各操作間に `CONFIRMATION_EVENT_DELAY`（1,000ms）の待機を入れる。

### BT-004 クリップボード機密コード自動消去タスク
- **目的**: コピーされたワンタイムパスワードがクリップボード上に長時間残留することによる漏洩を防ぐ。
- **処理手順**: コピー実行から30秒経過後に STA スレッド上で現在のクリップボード文字列を確認し、WinAuth がコピーしたコードと一致する場合のみ `Clipboard.Clear()` を実行する（ユーザーが別テキストをコピー済みの場合は上書き消去しない）。

### BT-006 コマンドライン引数（CLI）起動制御仕様
バッチファイル（`.bat`）やショートカットからの起動時に以下の引数を解釈する（配列境界チェック実装済）：
- `<ファイルパス>`: 読み込む設定ファイル（`winauth.xml`）を明示指定（相対パスは絶対パスへ正規化）。
- `-min` / `--minimize`: 起動時にメイン画面を表示せず最小化（またはシステムトレイ格納）状態で起動。
- `-p <password>` / `--password <password>`: マスターパスワードを引数から渡して起動時ロックを自動解除。
- `--proxy <[user[:pass]@]host[:port]>`: 外部 HTTPS 通信に使用するデフォルト Web プロキシを設定。
- `-l <level>` / `--log <level>`: `winauth.log` の出力ログレベル（`error`, `info`, `debug`, `trace`）を動的に有効化。
