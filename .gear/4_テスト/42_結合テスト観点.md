# 結合テスト観点

WinAuth の内部コンポーネント間結合、ファイル I/O・XML パーサー結合、暗号・ハードウェア結合、および外部 HTTPS API・OS サブシステム結合に関するテスト観点を以下に定義します。

---

## 1. テスト観点ツリー

### ITV-L1-001 暗号化基盤・ハードウェア連携結合（`Authenticator` ⇄ `System.Security.Cryptography` / `BouncyCastle` / `YubiKey`）
- **ITV-L2-001 WINAUTH4 AEAD 暗号化・復号・改ざん検知結合** [高]
  - **ITV-L3-001**: `EncryptSequence` で生成された暗号文字列が `WINAUTH4` ヘッダーを持ち、`DecryptSequence` で元の平文へ完全一致復号されること。
  - **ITV-L3-002**: 誤ったパスワード、暗号文または認証タグの1文字改ざん、AAD（保護種別・反復回数・ソルト）改ざん、および `WINAUTH4` ヘッダー除去に対して確実に `BadPasswordException` が送出され、未認証復号へフォールバックしないこと。
  - **ITV-L3-003**: DPAPI（`CurrentUser` / `LocalMachine`）単独およびパスワードとの複合保護が正常にラップ・アンラップされること。
- **ITV-L2-002 レガシー互換復号および安全なハッシュ選択** [高]
  - **ITV-L3-004**: 旧 `WINAUTH3` 形式で暗号化されたデータが `DecryptSequence` により透過的に判別・復号されること。
  - **ITV-L3-005**: `Authenticator.SafeHasher` に未知アルゴリズム名が渡された際、脆弱な SHA-1 へダウングレードせず `SHA256` が返却されること。
- **ITV-L2-003 YubiKey ネイティブ DLL ロード・例外安全結合** [高]
  - **ITV-L3-006**: 埋め込みリソースに `WinAuth.YubiKey.x86/x64.dll` が存在する場合に正常ロードされ、非存在時にはクラッシュせず `LibraryNotFoundException` が送出されること。

### ITV-L1-002 設定管理・XML パーサー・ファイル I/O 結合（`WinAuthHelper` ⇄ `WinAuthConfig` ⇄ FileSystem）
- **ITV-L2-004 XXE 防御・スキーマバージョン互換結合** [高]
  - **ITV-L3-007**: `SafeReaderSettings`（`DtdProcessing.Prohibit`）を用いた XML 読み込み時、DTD / 外部エンティティ参照を含む XML が `XmlException` で確実に拒否されること。
  - **ITV-L3-008**: 現行 `v4.0` および旧 `v3.5` 設定ファイルが正常ロードされ、上位バージョン（`v4.5` 等）のファイル読み込み時は例外を起こさず自動的に `IsReadOnly = true` が設定されること。
- **ITV-L2-005 パス正規化・アトミック保存・バックアップ退避結合** [高]
  - **ITV-L3-009**: 相対パスで指定された設定ファイル名が `LoadConfig` により絶対パスへ正規化されて `Filename` に保持されること。
  - **ITV-L3-010**: `SaveConfig` 実行時に `.tmp` 書き出しと読み戻しベリファイが行われ、初回 `WINAUTH3` 移行時は `.v3.bak`、通常更新時は `.bak` を保全してアトミックに本体が置換されること。`IsReadOnly` 時は上書きされないこと。

### ITV-L1-003 外部 HTTPS API 連携結合（`SteamClient` / 各 `Authenticator` ⇄ 外部サーバー）
- **ITV-L2-006 Steam Web API セッション・トレード確認結合** [高]
  - **ITV-L3-011**: 有効な `OAuthToken` による `GetWGToken`・`Logon` での Cookie 確立、`IdentitySecret` HMAC 署名による `/mobileconf/conf` 一覧取得および `/mobileconf/ajaxop`（`allow`/`cancel`）実行、`Logoff` によるセッション破棄が一貫して動作すること。
  - **ITV-L3-012**: 未認証・無効・期限切れトークン、HTTP 429/500系エラー、およびネットワークタイムアウト発生時に、ハングアップや平文秘密情報の露出を起こさず安全にエラー制御されること。
- **ITV-L2-007 時刻同期・サニタイズ・プロトコル通信結合** [高]
  - **ITV-L3-013**: Google / Steam / Battle.net / Trion との時刻同期で正常範囲（±24時間以内）の `ServerTimeDiff` が反映され、24時間超の異常ドリフトは棄却されること。また通信失敗時は規定時間（5分/60分）再試行が抑止されること。
  - **ITV-L3-014**: クエリ・フォームパラメータ（`+`, `@`, `&`, `=` 等）が `Uri.EscapeDataString` でサニタイズされ、インジェクションを防止できること。

### ITV-L1-004 UI コンポーネント・OS サブシステム結合（`WinAuthForm` ⇄ `MetroFramework` / `WinAPI`）
- **ITV-L2-008 画面操作・二重送信抑止・リサイズ追従結合** [中]
  - **ITV-L3-015**: トレード確認画面の連続更新・連続承認操作時に二重送信が抑止されること。
  - **ITV-L3-016**: `MetroForm`（`AboutForm`, `UpdateCheckForm` 等）の動的幅縮小・拡大時に、右上ウィンドウ制御ボタンがクライアント領域内右上に追従配置されること。
- **ITV-L2-009 クリップボード保護・ReDoS/XSS 防御結合** [中]
  - **ITV-L3-017**: `CopyCodeToClipboard` 実行時にクラウド同期・履歴除外属性が付与され、30秒後に自動クリアされること。
  - **ITV-L3-018**: 特殊メタ文字を含む Issuer の `ToUrl` 解析（`Regex.Escape` + 500ms タイムアウト）および `WinAuthHelper.HtmlEncode`（`&#39;` エスケープ）が安全に結合動作すること。
