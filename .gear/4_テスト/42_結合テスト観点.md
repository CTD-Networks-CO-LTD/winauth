# 結合テスト観点

## テスト観点ツリー

### ITV-L1-001 API結合

#### ITV-L2-001 HTTPメソッド・リクエスト通信制御 (Steam Web API連携エンドポイント群)

- **ITV-L3-001 POSTリクエスト実行およびHTTPS通信検証** [高]
  - 有効なOAuthアクセストークンを付与してPOST /IMobileAuthService/GetWGToken/v0001を呼び出した際、正常にWGTokenが返却されること
  - OAuthアクセストークンおよびWGTokenを付与してPOST /ISteamWebUserPresenceOAuth/Logon/v0001を呼び出した際、Webセッション認証Cookieが確立されること
  - POST /ISteamWebUserPresenceOAuth/Logoff/v0001の呼び出しによりSteam Webプレゼンスのログインセッションが破棄されること
- **ITV-L3-002 異常パラメータ・認証トークン不整合検証** [高]
  - 無効または期限切れのOAuthアクセストークンでPOST /IMobileAuthService/GetWGToken/v0001を要求した場合にエラーとなりSTEAM_AUTH_TOKEN_ERRORがハンドリングされること
  - 不正なWGTokenでPOST /ISteamWebUserPresenceOAuth/Logon/v0001を実行した際にセッション確立に失敗し適切な例外が通知されること
  - steamIdが欠落または無効な形式でリクエストされた場合にバリデーションエラーが発生すること
- **ITV-L3-003 通信タイムアウトおよび障害リカバリ動作検証** [中]
  - Steamサーバー応答遅延時にタイムアウトが検知され処理が中断すること
  - 通信遮断等のネットワークエラー発生時に安全にSTEAM_AUTH_TOKEN_ERRORが送出されUIへ制御が戻ること
  - セッション終了（ログオフ）要求時にサーバー側エラーが発生してもローカル端末のセッション状態が安全にクリアされること

#### ITV-L2-003 共通認証制御（認証トークン検証） (外部認証連携API群)

- **ITV-L3-007 共通未認証リクエスト制御** [高]
  - OAuthアクセストークンまたはWGTokenが未付与のリクエストに対して認証エラー（HTTP 401 Unauthorized等）が返却されること
  - 未認証エラー応答時にセッション確立やトークン更新処理が抑止され認証状態が破棄されること
  - トレード確認画面等の呼び出し元へ適切なエラー（STEAM_AUTH_TOKEN_ERROR等）が返却されアプリケーションがクラッシュしないこと
- **ITV-L3-008 共通無効トークン制御** [高]
  - 不正な文字列形式や改ざんされたOAuthアクセストークンまたはWGTokenを送信した場合に認証拒否されること
  - 無効トークン受信時にSteamClient内で安全に例外捕捉され、暗号化シークレットキーや機密情報がログ・画面等に露出しないこと
  - 無効トークン検知時にクライアント内部で無効なWebセッション認証Cookieが生成・保持されないこと
- **ITV-L3-009 共通期限切れトークン・セッション失効制御** [高]
  - 有効期限切れのOAuthアクセストークンまたはWGTokenを送信した場合にセッション確立が拒否されること
  - セッション失効検知時に既存のWebセッション認証CookieおよびWGTokenが破棄されること
  - 期限切れエラー応答の受信後、セッション再認証フローまたは再取得シーケンスが正しくトリガーされること

#### ITV-L2-004 共通認可制御（パーミッション検証） (外部認証連携API群)

- **ITV-L3-010 共通権限不足制御** [中]
  - LocalUser権限や対象操作パーミッションを満たさないコンテキストからのAPI呼び出しに対して認可エラー（HTTP 403 Forbidden等）が返却されること
  - 認可エラー発生時に外部認証セッション状態の更新やログオフ等の後続処理が実行されないこと
  - 権限不足エラーメッセージにサーバー内部情報や不要なスタックトレースが含まれず情報遮断されていること

#### ITV-L2-005 共通エラーハンドリング・通信障害制御 (外部認証連携API群)

- **ITV-L3-011 外部APIサーバー内部エラー（HTTP 500系）制御** [高]
  - Steam Web API側からHTTP 500（Internal Server Error）または502/503エラーが返却された場合に安全にハンドリングされること
  - 500系エラー発生時に不整合な認証CookieやWGTokenがメモリ上に残存しないこと
  - エラー内容に応じた例外処理が行われ、トレード確認画面側で処理失敗の旨が明瞭に通知されること
- **ITV-L3-012 共通通信タイムアウト・接続切断制御** [高]
  - 外部APIサーバーとの通信遅延時に規定タイムアウト時間でリクエスト処理が中断されること
  - 通信タイムアウト発生時に接続ソケット等のHTTPSリソースが適切に解放されること
  - ネットワーク切断や接続拒否時にアプリケーションがハングアップせず通信エラーとして制御されること

#### ITV-L2-006 同時実行・レート制限制御 (外部認証連携API群)

- **ITV-L3-013 共通レート制限（HTTP 429・流量制御）制御** [中]
  - 短時間での連続呼び出しにより外部API側からHTTP 429（Too Many Requests）が返却された場合に安全にハンドリングされること
  - レート制限検知時に過剰なリトライリクエストが送信されず適切に待機または中断されること
  - レート制限エラー発生時にもローカルの暗号化保護データや既存のセッション状態が破損・改ざんされないこと

### ITV-L1-002 画面⇄サーバ結合

#### ITV-L2-002 トレード確認画面・API連携状態制御 (トレード確認画面とSteamClient間連携)

- **ITV-L3-004 画面表示に伴うセッション確立シーケンス検証** [高]
  - トレード確認画面表示トリガーにより自動的にGetWGTokenおよびLogon APIが順次実行されセッションCookieがバインドされること
  - 認証トークン取得からログオン成功まで画面のローディング状態が正しく維持されること
  - 認証失敗時にエラーメッセージが表示されトレード確認一覧照会処理への遷移が阻止されること
- **ITV-L3-005 二重サブミット・連続実行抑止検証** [中]
  - トレード確認画面での一覧更新要求ボタン連打時に多重でLogon/GetWGToken APIが呼び出されないよう制御されていること
  - セッション更新処理中にトレード確認画面が閉じられた場合、通信が安全にキャンセルされること
  - ログオフ処理実行中に連続して閉じる・ログオフ操作が行われても多重ログオフエラーを起こさないこと
- **ITV-L3-006 画面終了時のセッション破棄・クリーンアップ検証** [中]
  - トレード確認画面を閉じた際にPOST /ISteamWebUserPresenceOAuth/Logoff/v0001が呼び出されセッションCookieが破棄されること
  - ログオフ完了後に保持されていたWGTokenおよびWebセッション認証Cookieがメモリ上からクリアされること
  - 再ログイン時に既存のセッション情報が混入せず新規にGetWGTokenから再取得が実行されること
