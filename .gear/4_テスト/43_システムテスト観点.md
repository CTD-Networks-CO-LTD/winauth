# システムテスト観点

WinAuth システム全体の機能要件（`FR-001`〜`FR-014`）および非機能要件（`NFR-001`〜`NFR-012`）を網羅するシステムテスト観点を以下に定義します。

---

## 1. テスト観点ツリー

### STV-L1-001 機能要件検証（エンドツーエンド業務シナリオ）

- **STV-L2-001 標準 TOTP / HOTP 認証器の登録・算出・更新シナリオ** (`FR-001`, `FR-002`, `FR-006`) [高]
  - **STV-L3-001**: 汎用追加画面および Google / Microsoft / GuildWars / Okta 各追加画面から Base32 秘密鍵、`otpauth://` URI、QRコード画像を用いて正常登録でき、周期境界（30秒等）で自動更新されること。
  - **STV-L3-002**: HOTP 認証器の登録後、手動コード表示操作ごとにカウンターが `+1` 加算され、RFC 4226 標準テストベクタと一致するコードが順次生成・保存されること。
  - **STV-L3-003**: 空の名称や不正な Base32 文字列、非対応 URI スキーム入力時に適切なエラーダイアログが表示され不正登録が阻止されること。
- **STV-L2-002 専用サービス（Battle.net / Steam / Trion）登録・トレード確認シナリオ** (`FR-003`, `FR-004`, `FR-005`, `FR-006`) [高]
  - **STV-L3-004**: Battle.net（8桁・シリアル/リストアコード）、Trion（8桁・デバイスID）、Steam Guard（5桁英数字・リカバリーコード）の各専用コード算出およびシークレット閲覧画面が正常動作すること。
  - **STV-L3-005**: Steam トレード確認画面（`SCR-012`）にてセッション確立、保留トレード一覧表示、承認（Accept）/ 拒否（Reject）、および自動確認ポーリングが正常に機能すること。
- **STV-L2-003 多層保護（マスター保護・個別保護・YubiKey）およびステップアップ認証** (`FR-007`, `FR-008`, `FR-009`) [高]
  - **STV-L3-006**: マスター保護画面（`SCR-007`）でパスワード、DPAPI（Machine / User）、YubiKey（Slot 1 / 2）の各単独および複合保護を設定・変更・解除でき、再起動時に正しくロック解除が要求されること。
  - **STV-L3-007**: 個別パスワード保護（`SCR-008` / `SCR-009`）設定時に対象項目のみロックされ、またシークレット表示・エクスポート・保護変更時に `GetPasswordForm` による本人再確認が強制されること。
- **STV-L2-004 デスクトップ操作支援・インポート/エクスポート・ポータブル/CLI運用** (`FR-010`〜`FR-014`) [中]
  - **STV-L3-008**: 時刻同期（`Sync Time`）、クリップボードコピー、グローバルホットキー（`Notify` / `Copy` / `Inject` / `Advanced`）、システムトレイ常駐、並び替え・カスタムアイコン変更が正常動作すること。
  - **STV-L3-009**: `.txt` / `.zip`（パスワード保護）/ `.pgp`（OpenPGP暗号化）のエクスポートと再インポートが可逆的に一致すること。
  - **STV-L3-010**: EXE 同階層 `winauth.xml` によるポータブルモード（レジストリ非変更）および CLI 引数（`-min`, `-p`, `--proxy`, `-l`, ファイルパス指定）が仕様通り動作すること。

---

### STV-L1-002 非機能要件検証（セキュリティ・互換性・可用性・UI・CI/CD）

- **STV-L2-005 セキュリティ防御・機密保護検証** (`NFR-001`〜`NFR-005`) [高]
  - **STV-L3-011 (WINAUTH4 改ざん・ヘッダー除去拒否)**: `WINAUTH4` 暗号文・認証タグ・AAD の改ざんやマジックヘッダー除去を行った際、100% 復号拒否（`BadPasswordException`）され平文フォールバックしないこと。
  - **STV-L3-012 (XXE / ReDoS / XSS / インジェクション遮断)**: DTD 含有 XML の読み込み遮断、特殊記号を含む Issuer の 500ms 以内安全解析、HTML シングルクォートエスケープ、URL パラメータエンコードが機能すること。
  - **STV-L3-013 (異常ドリフト棄却・機密非露出・30秒クリア)**: 24時間超のサーバー時刻差分の棄却、例外メッセージからの秘密鍵非露出、およびコピー後30秒でのクリップボード自動消去が機能すること。
- **STV-L2-006 後方・前方互換性および耐障害アトミック保存検証** (`NFR-006`, `NFR-007`, `NFR-008`) [高]
  - **STV-L3-014 (レガシー互換移行)**: 旧 `WINAUTH3` / v3.5 設定ファイルを透過的に復号・利用でき、初回保存時に `.v3.bak` が自動保全されること。また読み取り専用属性の旧ファイルは書き換えられないこと。
  - **STV-L3-015 (上位バージョン保護)**: 上位バージョン（`version="4.5"` 等）の設定ファイルを開いた際にクラッシュせず `IsReadOnly = true` が強制され、データ破壊が防止されること。
  - **STV-L3-016 (DLL不在時可用性・単一起動制御)**: YubiKey ネイティブ DLL 非存在時や未接続時にクラッシュしないこと。また二重起動時に既存ウィンドウが前面化されること。
- **STV-L2-007 UI描画追従性・応答性能・CI/CD リリース検証** (`NFR-009`〜`NFR-012`) [中]
  - **STV-L3-017 (動的リサイズ追従)**: `AboutForm` や `UpdateCheckForm` 等のウィンドウ幅縮小・拡大時に右上タイトルバーボタン（最小化・最大化・閉じる）がクライアント領域内へ即座に追従すること。
  - **STV-L3-018 (CI/CD 自動ビルド・配布整合性)**: GitHub Actions `release.yml` にて x86/x64 YubiKey DLL ビルド、xUnit テスト合格、`PublishSingleFile` による単一 `WinAuth.exe` 発行、通常版 `WinAuth-{tag}.zip` およびポータブル版 `WinAuth-{tag}-portable.zip`（`winauth.xml`同梱）の生成、およびアセンブリバージョン整合が確認できること。
