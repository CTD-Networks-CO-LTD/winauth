# プロジェクト概要

## 1. 背景と目的
**Windows Authenticator（WinAuth）** は、RFC 6238（時刻ベース TOTP）および RFC 4226（カウンターベース HOTP）に準拠した、Windows デスクトップ環境向けのポータブルなオープンソース二要素認証（2FA / MFA）クライアントアプリケーションです。

オリジナルの WinAuth（Colin Mackie 氏開発、v3.x 系）は長年にわたり広く利用されてきましたが、レガシーな .NET Framework 環境への依存や暗号化設計の経年化などの課題を抱えていました。本プロジェクト（v4.0 以降、CTD Networks Co., Ltd. 改修版）は、オリジナルの利便性・ポータブル運用性・後方互換性を損なうことなく、最新ランタイムへの移行と現代的な暗号・セキュリティ基準への刷新を実現することを目的としています。

## 2. システムの特徴・主要価値
1. **標準規格および多様なゲーム・Web サービスへの対応**
   - Google Authenticator、Microsoft Authenticator、Okta Verify 等の標準 TOTP（RFC 6238）およびカウンター型 HOTP（RFC 4226）に対応。
   - Battle.net（登録・リストア対応）、Steam（Steam Guard 5桁英数字コード生成およびモバイルトレード確認の照会・承認・拒否）、Guild Wars 2、Trion / Glyph（Rift / ArcheAge）などサービス固有の認証プロトコルをサポート。
   - QR コード画像（ファイル・URL・Data URI）からの `otpauth://` 読み取り（ZXing.Net）に対応。
2. **刷新された暗号基盤（WINAUTH4）と多層防御**
   - **PBKDF2-HMAC-SHA256（600,000 反復）** による鍵導出と **AES-256-GCM（認証付き暗号: AEAD）** を採用し、秘密鍵データの機密性に加えて AAD（追加認証データ）による完全性検証・改ざん検知を実現。
   - マスターパスワード保護、Windows DPAPI（現在ユーザー / ローカルマシン紐付け）、YubiKey（USB HID チャレンジ・レスポンス + HKDF-SHA256 鍵導出）、および認証器単位の個別パスワード保護を組み合わせ可能。
   - XXE（XML 外部エンティティ）遮断、ReDoS（正規表現サービス妨害）対策、異常クロックドリフト（24時間超）棄却、クリップボード保護および30秒自動消去、TLS 1.2/1.3 強制、暗号鍵のメモリゼロクリア等の包括的な脆弱性対策を実装。
3. **高い後方・前方互換性とポータブル運用**
   - 従来の WinAuth 3 系（`WINAUTH3` 形式）および 2 系の設定ファイルを透過的に読み込み可能（初回移行時は `.v3.bak` ロールバック用バックアップを自動生成）。
   - 上位バージョン（v4.5 等）の設定ファイルを検知した場合は自動的に読み取り専用（`IsReadOnly`）として扱い、未知の将来設定要素の破損を防止。
   - インストーラー不要の単一実行ファイル（`WinAuth.exe`）として配布され、実行ファイルと同階層に `winauth.xml` を配置することでレジストリを使用しない完全なポータブルモードで動作。
4. **効率的なデスクトップ操作性**
   - MetroFramework によるモダン UI（Light / Dark テーマ、アクセントカラー切替、動的リサイズ追従）。
   - システムトレイ常駐、グローバルホットキー割り当て、アクティブウィンドウまたは指定ウィンドウへの自動キー入力（Auto-Type / InputSimulator）。

## 3. 対象ユーザーと利用シーン
| 対象ユーザー | 主な利用シーン |
| --- | --- |
| 一般ユーザー・ゲーマー | スマートフォンを持たない環境や PC 作業中に、Google / Microsoft 等の Web サービスや Steam（トレード確認含む）・Battle.net 等のゲームアカウントへ素早く 2FA ログインを行う。 |
| 社内システム利用者・開発者 | Okta Verify や業務 Web システムの 2FA トークンを PC 上で安全に管理し、ホットキー自動入力により日常の認証作業を効率化する。USB メモリや社内共有フォルダを用いたポータブル運用を行う。 |
| セキュリティ重視ユーザー | マスターパスワード＋DPAPI＋YubiKey ハードウェアトークンを組み合わせた多要素保護や、OpenPGP / 暗号化 ZIP による安全なバックアップ運用を行う。 |

## 4. ソリューション構成と CI/CD 体制
| プロジェクト / ディレクトリ | 役割・概要 | ターゲット / 技術 |
| --- | --- | --- |
| `WinAuth/` | メイン GUI アプリケーション（フォーム群、設定管理 `WinAuthConfig`、ホットキー、トレイ制御） | `net10.0-windows` (C#, WinForms) |
| `Authenticator/` | 認証アルゴリズムコア、各種サービス連携、`WINAUTH4`/`WINAUTH3` 暗号基盤、YubiKey ラッパー | `net10.0-windows` (C#, System.Security.Cryptography, BouncyCastle) |
| `WinAuth.YubiKey/` | YubiKey USB HID チャレンジ・レスポンス通信用ネイティブライブラリ（x86 / x64） | C / VC++ (`vcxproj`, MSBuild) |
| `Third Party/` | 同梱サードパーティ製ライブラリ（`MetroFramework`, `MetroFramework.Fonts`, `InputSimulator`） | C# クラスライブラリ |
| `Authenticator.Tests/` | RFC 準拠性、セキュリティ対策（Phase 2〜4）、不具合修正検証用の自動単体テスト | `net10.0-windows` (xUnit) |
| `.github/workflows/release.yml` | ネイティブ DLL ビルド、全自動テスト、`PublishSingleFile` 単一 EXE 生成、通常版/ポータブル版 ZIP 化、GitHub Release 公開 | GitHub Actions (`windows-latest`) |
