# 機能要件一覧

業務要件を実現するためのシステム機能要件を以下に定義します。

| 機能ID | 機能名 | 機能概要・仕様 | 関連業務要件 | 優先度 |
| --- | --- | --- | --- | --- |
| FR-001 | 時間型ワンタイムパスワード（TOTP）生成・自動更新機能 | RFC 6238 に準拠し、Base32 デコードしたシークレットキーと補正済み時刻から TOTP（既定6桁・30秒周期、任意桁数・周期・HMAC-SHA1/SHA256/SHA512選択可）を生成する。自動更新設定時は残り時間インジケーターを描画し周期境界で自動再計算する。 | BR-001 | 高 |
| FR-002 | カウンター型ワンタイムパスワード（HOTP）生成機能 | RFC 4226 に基づき、ユーザーのコード表示操作ごとにカウンター値をインクリメントしてワンタイムパスワードを算出し、更新後のカウンター値を設定ファイルへ保存する。 | BR-001 | 中 |
| FR-003 | Battle.net 二要素認証登録・リストア・生成機能 | Blizzard モバイル認証サーバーと RSA 暗号化通信を行い、リージョン（US/EU/KR/CN）自動判定による新規シリアル発行（Enroll）、10文字リストアコードによる復元（PaperRestore）、および 8桁 TOTP 生成を提供する。 | BR-002 | 高 |
| FR-004 | Steam Guard 認証登録・5桁英数字コード生成機能 | Steam OAuth ログインおよび SMS アクティベーション連携（`AddAuthenticator` / `FinalizeAddAuthenticator`）によるモバイル認証器登録と、Steam 固有文字セット（26文字）による 5桁 Steam Guard コード生成を行う。 | BR-002 | 高 |
| FR-005 | Steam トレード確認照会・承認・拒否・自動ポーリング機能 | `SteamClient` により WGToken 取得・Web セッション確立を行い、`IdentitySecret` による HMAC 署名付きで保留中トレード・マーケット出品の一覧取得、詳細確認、個別承認/拒否、および定期ポーリングによる自動承認/通知を行う。 | BR-006 | 高 |
| FR-006 | マルチサービス認証プロファイル・QRコード読取機能 | Google、Microsoft、Guild Wars 2、Okta Verify、および Trion / Glyph（新規デバイスキー発行・秘密の質問による復元対応）の専用追加フォームを提供する。ZXing.Net により画像ファイル・URL・Data URI の QR コードから `otpauth://` URI を解析登録できる。 | BR-001, BR-002, BR-008 | 高 |
| FR-007 | WINAUTH4 多層暗号化・マスター保護機能 | 設定ファイル全体の `<data>` 要素を `WINAUTH4` 形式（PBKDF2-HMAC-SHA256 600,000反復 + AES-256-GCM AEAD + AAD完全性保護）で暗号化・復号する。パスワード保護に加え Windows DPAPI（CurrentUser / LocalMachine）との組み合わせに対応する。 | BR-003 | 高 |
| FR-008 | 個別認証器パスワード保護・シークレット閲覧保護機能 | 認証器単位で独立したパスワード保護（`SetPasswordForm` / `UnprotectPasswordForm`）を設定でき、必要な時のみ一時復号してコードを表示する。またシークレットキー・QRコード・リストアコード閲覧時は事前に現在のマスターパスワード再確認（`GetPasswordForm`）を要求する。 | BR-003 | 高 |
| FR-009 | YubiKey ハードウェアトークン連携機能 | USB 接続された YubiKey（Vendor ID `0x1050`）を検出し、Slot 1 / Slot 2 への設定書き込みおよび HMAC-SHA1 チャレンジ・レスポンス結果からの HKDF-SHA256 鍵導出による構成データ保護を行う。USB 着脱検知（`WM_DEVICECHANGE`）にも対応する。 | BR-004 | 中 |
| FR-010 | サーバー時刻同期・異常ドリフト防御機能 | Google（HTTPS `Date` ヘッダー）、Steam（`QueryTime`）、Battle.net（`time.htm`）、Trion（`/time`）の各エンドポイントと通信して `ServerTimeDiff` を算出・保持する。差分が絶対値24時間を超える場合は異常値として棄却し、通信失敗時は一定時間（5分/60分）再試行を抑止する。 | BR-005 | 高 |
| FR-011 | クリップボード保護コピー・グローバルホットキー自動入力機能 | コードコピー時にクラウドクリップボード同期・履歴保存除外フラグ（`CanIncludeInClipboardHistory=0` 等）を付与し、30秒後に自動消去する。また認証器ごとにグローバルホットキーを設定し、通知表示・クリップボードコピー・指定ウィンドウへのキー送信（Inject / Advanced スクリプト）を実行する。 | BR-007 | 高 |
| FR-012 | インポート・エクスポートおよびレガシー互換移行機能 | `otpauth://` KeyUri 形式テキスト（`.txt`）、パスワード暗号化 ZIP（`.zip`）、OpenPGP 暗号化（`.pgp`）によるエクスポート・インポート、および WinAuth v2 XML のインポートを提供する。また `WINAUTH3` 暗号データの透過的復号と `.v3.bak` 自動退避を行う。 | BR-008 | 高 |
| FR-013 | システムトレイ常駐・単一インスタンス・ポータブル起動制御機能 | ミューテックス（`SingleGlobalInstance`）による多重起動防止（既存ウィンドウの前面呼び出し）、システムトレイ常駐・Windows 起動時自動実行、実行ファイル同階層配置時のポータブルモード動作、および CLI 引数（`-min`, `-p`, `--proxy`, `-l`, 設定ファイルパス指定）を処理する。 | BR-007, BR-009 | 中 |
| FR-014 | MetroスタイルUI・アイコン管理・診断/更新チェック機能 | MetroFramework による画面描画・ウィンドウ自動リサイズ（`AutoSize`）・常に手前に表示（`AlwaysOnTop`）・内蔵/カスタム PNG アイコン（Base64保持）の適用・並び替え、および診断確認（`DiagnosticForm`）・更新チェック（`UpdateCheckForm`）・例外レポート（`ExceptionForm`）を提供する。 | BR-010 | 低 |
