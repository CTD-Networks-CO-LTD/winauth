# テーブル定義

> **データストア設計方針**: WinAuth は外部 RDBMS を使用しないスタンドアロン型デスクトップアプリケーションであり、すべての構成データおよび認証器データをローカル XML ファイル（**`winauth.xml`**）および環境設定ストア（ポータブル時は XML 内 `<settings>`、通常時は Windows レジストリ `HKCU\Software\WinAuth3`）に永続化します。本書ではこれらの永続化スキーマおよび暗号化ペイロード構造を定義します。

---

## 1. 永続化ストレージ一覧

| 論理ストアID | 物理格納先 / 要素名 | 対応クラス | 概要 |
| --- | --- | --- | --- |
| DS-001 | `%APPDATA%\WinAuth\winauth.xml` または `<EXE同階層>\winauth.xml` (`<WinAuth>`) | `WinAuthConfig` | アプリケーション全体設定および認証器リストのルート XML ドキュメント |
| DS-002 | `<data>` 要素 & `WINAUTH4` ペイロード | `Authenticator` (Crypto) | マスター保護有効時に `<WinAuthAuthenticator>` 群を暗号化格納する AEAD コンテナ |
| DS-003 | `<WinAuthAuthenticator>` 要素 | `WinAuthAuthenticator` | 個別認証器の表示名・アイコン・コピー設定・ホットキー等のラッパー情報 |
| DS-004 | `<hotkey>` 要素 | `HotKey` | 認証器に割り当てられたグローバルショートカットキーと自動入力アクション定義 |
| DS-005 | `<authenticatordata>` 要素 | `Authenticator` 派生各クラス | 秘密鍵（`secretdata`）、サーバー時刻差、アルゴリズム等のコア認証データ |
| DS-006 | `<settings>` 要素 / `HKCU\Software\WinAuth3` | `WinAuthConfig` / `WinAuthHelper` | ポータブル KVS 設定または Windows レジストリ設定（`Language` 含む）・自動実行設定 |

## 2. スキーマ・項目詳細定義

### DS-001 ルート設定要素 `<WinAuth>` (`WinAuthConfig`)

| 要素 / 属性名 | 種別 | データ型 | 必須 | 既定値 | 説明 |
| --- | --- | --- | --- | --- | --- |
| `@version` | 属性 | decimal | ○ | `4.0` | 設定ファイルフォーマットバージョン（`CURRENTVERSION` より大の場合は `IsReadOnly=true` で保護） |
| `alwaysontop` | 要素 | boolean | ○ | `false` | メインウィンドウを常に最前面に表示するか |
| `usetrayicon` | 要素 | boolean | ○ | `false` | 最小化・クローズ時にシステムトレイへ常駐するか |
| `notifyaction` | 要素 | enum文字列 | - | `Notification` | トレイアイコン操作時の既定動作（`Notification` / `CopyToClipboard` / `HotKey`） |
| `startwithwindows` | 要素 | boolean | ○ | `false` | Windows ログオン時に自動起動するか |
| `autosize` | 要素 | boolean | ○ | `true` | 登録認証器数に応じてウィンドウ高さを自動調整するか |
| `left` / `top` | 要素 | int | - | `0` | 前回終了時のウィンドウ X / Y 座標 |
| `width` / `height` | 要素 | int | - | 初期サイズ | 前回終了時のウィンドウ幅・高さ |
| `shadowtype` | 要素 | string | - | `Flat` | MetroForm ウィンドウドロップシャドウ種別 |
| `language` | 要素 | string | - | 未設定時OS判定 | UI 表示言語（`"Japanese"` / `"English"`）。`<data>` 暗号化ブロックより前に平文配置し、パスワード入力前から適用する |
| `pgpkey` | 要素 | string | - | `null` | ユーザー設定の独自 PGP 公開鍵テキスト |
| `data` | 要素 | Hex文字列 | 条件 | - | マスター保護有効時の暗号化コンテナ（保護なし時は省略され直下に `WinAuthAuthenticator` を配置） |

### DS-002 暗号化コンテナ `<data>` および `WINAUTH4` バイナリ構造

`<data encrypted="[フラグ]" sha1="[ハッシュ]">` 要素の本文は、`WINAUTH4` ヘッダー（16進文字列 `57494E4155544834`）に続けて以下のバイナリペイロード（DPAPI 指定時はさらに `ProtectedData.Protect` 適用後）を16進エンコードした文字列を保持します。

**`@encrypted` 属性フラグ文字**: `p`=Explicitパスワード, `u`=DPAPI CurrentUser, `m`=DPAPI LocalMachine, `a`=YubiKey Slot1, `b`=YubiKey Slot2

| 順序 | フィールド名 | バイト長 | エンディアン / 型 | 説明 |
| --- | --- | --- | --- | --- |
| Header | Magic Header | 8 bytes | ASCII (`WINAUTH4`) | 平文プレフィックス（Hex 16文字）。AAD（追加認証データ）の先頭にも含まれる |
| 1 | `typeBytes` | 4 bytes | Big-Endian `int32` | `PasswordTypes` ビットフラグ値（AAD に含まれるため保護方式の改ざんを検知） |
| 2 | `iterBytes` | 4 bytes | Big-Endian `int32` | PBKDF2 反復回数（現行固定値: `600,000`、AAD に含まれる） |
| 3 | `salt` | 16 bytes | `byte[16]` | CSPRNG 生成ソルト（PBKDF2 / HKDF 鍵導出および AAD に使用） |
| 4 | `nonce` | 12 bytes | `byte[12]` | AES-256-GCM 用 96bit ランダムナンス |
| 5 | `tag` | 16 bytes | `byte[16]` | AES-256-GCM 128bit 認証タグ（改ざん・誤鍵時に復号拒否） |
| 6 | `hasInnerKey` | 1 byte | `byte` (`0` or `1`) | パスワード/YubiKey なしの DPAPI 単独保護時に内部鍵を含む場合 `1` |
| 7 | `innerKey` | 0 or 32 bytes | `byte[32]` | `hasInnerKey == 1` の場合のみ存在するランダム 256bit AES 鍵 |
| 8 | `ciphertext` | 可変長 | `byte[]` | `<config><WinAuthAuthenticator>...</config>`（または個別 `SecretData`）の暗号文 |

| `@type` | 属性 | string | ○ | 完全修飾クラス名（例: `WinAuth.GoogleAuthenticator`, `WinAuth.SteamAuthenticator` 等） |
| `name` | 要素 | string | ○ | 画面に表示するアカウント・サービス名称 |
| `created` | 要素 | long | ○ | 作成日時（Unix エポックからの UTC ミリ秒） |

| `authenticatordata` | 要素 | 複合要素 | ○ | 認証器コア秘密情報（DS-005 参照） |

### DS-004 ショートカットキー要素 `<hotkey>` (`HotKey`)

| 要素名 | データ型 | 説明 |
| --- | --- | --- |
| `modifiers` | string | 修飾キーフラグ文字列（`Shift`, `Control`, `Alt` の組み合わせ） |

### DS-005 認証器コア要素 `<authenticatordata>` およびプロバイダ別 `secretdata` 構造

個別パスワード保護（`@encrypted="p"` 等）が有効な場合は `<authenticatordata>` 直下に `WINAUTH4` 暗号化文字列が格納され、未保護（またはマスター保護 `<data>` 内部）の場合は以下の子要素を持ちます。

| 要素名 | データ型 | 説明 |
| --- | --- | --- |
| `servertimediff` | long | 外部サーバーとの時刻差分（ミリ秒） |
| `lastservertime` | long | 最終時刻同期実行時のローカル `DateTime.Ticks` |
| `secretdata` | string | パイプ（`|`）区切りのプロバイダ別秘密情報（下表参照） |
| `period` / `digits` / `hmac` | int / string | 周期秒数（既定 `30`）、コード桁数（既定 `6`〜`8`）、HMAC種別（`SHA1`/`SHA256`/`SHA512`） |

**プロバイダ別 `secretdata` 内部フォーマット（`|` 区切り）**:
- **`GoogleAuthenticator` / `Microsoft` / `GuildWars` / `OktaVerify`**: `<SecretKey(Hex)>|<Digits>|<Period>|<HMACType>|<Issuer(Hex)>`
- **`HOTPAuthenticator`**: `<基底SecretData>|<Counter(long)>`
- **`BattleNetAuthenticator`**: `<基底SecretData>|<Serial(UTF8-Hex)>`
- **`TrionAuthenticator`**: `<基底SecretData>|<Serial(UTF8-Hex)>|<DeviceId(UTF8-Hex)>`
- **`SteamAuthenticator`**: `<基底SecretData>|<Serial(Hex)>|<DeviceId(Hex)>|<SteamData JSON(Hex)>|<SessionData JSON(Hex)>`
  - `SteamData` JSON には `shared_secret`, `identity_secret`, `revocation_code`, `steamid` 等を保持。
  - `SessionData` JSON には `steamid`, `cookies`, `oauthtoken`, `confs`（自動確認ポーラー設定）を保持。
