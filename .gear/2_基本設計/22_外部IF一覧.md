# 外部IF一覧

WinAuth が外部サーバー・ハードウェアデバイス・OS サブシステムと連携するインターフェースを以下に定義します。

## 1. 連携先システム・デバイス概要

| 連携先名称 | 種別 | 役割・連携概要 | 関連IF |
| --- | --- | --- | --- |
| Steam Web API / Steam Community | 外部Webサービス (Valve) | OAuth モバイルログイン、Steam Guard 2FA 登録、時刻同期、Web セッション確立、およびモバイルトレード確認の照会・承認・拒否 | IF-001, IF-002 |
| Battle.net Mobile Service / GeoIP | 外部Webサービス (Blizzard / Wikimedia) | クライアント地域の自動判定、RSA 暗号化による新規シリアル・秘密鍵発行（Enroll）、リストアコード復元、および時刻同期 | IF-003 |
| Trion Worlds Auth API | 外部Webサービス (Trion) | Glyph / Rift 向けデバイスキーの新規発行、秘密の質問による復元、およびサーバー時刻同期 | IF-004 |
| Google HTTPS エンドポイント | 外部Webサービス (Google) | 標準 TOTP 認証器向けの基準 UTC 時刻（HTTP `Date` ヘッダー）取得 | IF-005 |
| YubiKey ハードウェアトークン | 外部USBデバイス (Yubico) | USB HID 経由でのデバイス情報取得、スロット設定、および HMAC-SHA1 チャレンジ・レスポンス鍵導出 | IF-006 |
| Windows OS サブシステム | ローカルOS API (Win32 / DPAPI) | グローバルホットキーフック、自動キーストローク送信（`SendInput`）、クリップボード保護制御、DPAPI 暗号化 | IF-007 |

## 3. 主要インターフェース詳細定義

### IF-001 / IF-002 Steam Web API およびトレード確認連携
- **接続先ベースURL**: `https://api.steampowered.com` および `https://steamcommunity.com`
- **認証・署名方式**: OAuth アクセストークン、`steamLogin` / `steamLoginSecure` Cookie、および `IdentitySecret` による HMAC-SHA1 署名タグ（`tag`: `conf` / `details` / `allow` / `cancel`）
- **異常時制御**: ネットワーク障害や無効トークン時は機密情報を含まないエラーメッセージを通知し、時刻同期失敗時は 60 分間再試行を抑止する。

| 項目名 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `access_token` | string | ○ | Steam モバイル OAuth アクセストークン（WGToken 取得・Presence Logon/Logoff・2FA登録用） |
| `steamid` | string | ○ | 64bit Steam アカウント識別子（例: `76561198...`） |
| `device_id` (`a`) | string | ○ | 登録端末識別子（`android:<UUID>` 形式） |
| `authenticator_code` | string(5) | 条件 | アクティベーション完了時に送信する 5桁 Steam Guard コード |
| `activation_code` | string | 条件 | SMS で受信したアクティベーションコード |
| `k` | string | ○ | Base64 エンコードされた HMAC-SHA1 確認署名ハッシュ（`IdentitySecret` + `time` + `tag`） |
| `t` | long | ○ | 署名生成に使用したサーバー補正済み Unix 秒タイムスタンプ |
| `op` | string | 条件 | トレード確認操作種別（`allow`: 承認 / `cancel`: 拒否） |
| `cid` / `ck` | string | 条件 | 対象トレード確認 ID（`data-confid`）および確認キー（`data-key`） |

### IF-003 Battle.net 登録・復元・時刻同期連携
- **接続先URL**: `https://mobile-service.blizzard.com`（CN地域のみ `https://mobile-service.battlenet.com.cn`）、地域判定 `https://geoiplookup.wikimedia.org`
- **暗号化方式**: 20byte ワンタイムパッド＋国コード＋デバイスモデル（計38byte）を Blizzard RSA 公開鍵（1024bit）で暗号化して送信し、応答45byteを XOR 復号して 20byte 秘密鍵と 17byte シリアルを取得。

| エンドポイントパス | メソッド | 入出力サイズ | 説明 |
| --- | --- | --- | --- |
| `/enrollment/enroll2.htm` | POST | Req: 128B / Res: 45B | 新規認証器シリアルおよび秘密鍵の発行 |
| `/enrollment/time.htm` | GET | Res: 8B (Big-Endian ms) | Battle.net サーバー UTC ミリ秒時刻の取得 |
| `/enrollment/initiatePaperRestore.htm` | POST | Req: Serial / Res: 32B | リストア用 32byte チャレンジの取得 |
| `/enrollment/validatePaperRestore.htm` | POST | Req: Serial+RSA / Res: 20B | HMAC-SHA1 応答検証および暗号化秘密鍵の復元 |

### IF-004 / IF-005 Trion および Google 時刻同期連携
- **Google 時刻同期**: `GET https://www.google.com`（タイムアウト 5,000ms）の HTTP レスポンスヘッダー `Date` から UTC 時刻を取得。`|ServerTimeDiff| > 86,400,000ms`（24時間超）は異常値として棄却し、通信失敗時は 5 分間再試行を抑止。
- **Trion 連携**: `POST https://rift.trionworlds.com/external/create-device-key`（XML `<DeviceKey>` 応答、`XmlResolver = null` で安全解析）および `GET https://auth.trionworlds.com/time` による時刻同期。

### IF-006 YubiKey ハードウェアトークン連携
- **連携ライブラリ**: `WinAuth.YubiKey.x86.dll` / `WinAuth.YubiKey.x64.dll`（プロセスビット数に応じ埋め込みリソースから一時展開して `LoadLibrary` 実行）
- **対象ハードウェア**: Vendor ID `0x1050`（YubiKey Standard / NEO / YubiKey 4 / Plus 各 PID 対応）
- **主要ネイティブ関数**: `IsInserted()`, `GetInfo(out INFO)`, `SetChallengeResponse(slot, secret, keysize, userpress, access_code)`, `ChallengeResponse(slot, may_block, challenge, len, response, resp_len)`
- **フォールバック仕様**: DLL 未埋め込み時は `LibraryNotFoundException`、未挿入時は `BadYubiKeyException` を送出しプロセス異常終了を防止。
