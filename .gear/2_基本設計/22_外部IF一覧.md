# 外部IF一覧

## 連携概要

### WinAuth（自システム）
開発対象のWindowsデスクトップ向け二要素・多要素認証クライアントアプリケーション
- IF-001 Steam認証およびトレード確認連携（→ Steam Web API）
- IF-002 サーバー時刻同期連携（→ 外部時刻同期サーバー（Google等））
- IF-003 YubiKeyハードウェアトークン連携（→ YubiKey）

### Steam Web API（外部）
SteamGuard認証トークン発行およびトレード確認を管理するValve社のWeb APIサーバー
- IF-001 Steam認証およびトレード確認連携（← WinAuth）

### 外部時刻同期サーバー（Google等）（外部）
ワンタイムパスワード生成のための正確な時刻差分（ServerTimeDiff）を提供する外部HTTPSエンドポイント
- IF-002 サーバー時刻同期連携（← WinAuth）

### YubiKey（外部）
USB HID接続によりチャレンジ・レスポンス認証を実行するハードウェアセキュリティトークン
- IF-003 YubiKeyハードウェアトークン連携（← WinAuth）

## IF詳細

### IF-001 Steam認証およびトレード確認連携

- **連携内容:** SteamClientを介してOAuthトークン取得やトレード確認情報の取得・承認・拒否を実施する
- **連携元→連携先:** WinAuth → Steam Web API
- **タイミング:** 随時 / SteamGuardコード生成時およびトレード確認の取得・承認・拒否操作時
- **方式:** REST API
- **データ形式:** JSON
- **認証:** OAuth / セッションCookie（Uri.EscapeDataStringサニタイズ適用）
- **想定件数・量:** ユーザー操作時随時（1操作あたり1〜数リクエスト）
- **エラー時:** 通信失敗時はエラーメッセージをUIに表示し、シークレット等の機密情報を漏洩させずに処理を中断する
- **関連:** FR-004, NFR-005

#### 項目定義

| 項目名 | 型 | 桁数 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| steamid | 文字列 | 20 | ○ | 対象のSteamアカウント識別子 |
| oauth_token | 文字列 | 未定義 | ○ | Web APIアクセス用のOAuth認証トークン |
| op | 文字列 | 10 | - | トレード確認に対する操作種別（allow / cancel） |
| cid | 文字列 | 未定義 | - | 承認・拒否対象のトレード確認ID |
| ck | 文字列 | 未定義 | - | トレード確認検証キー |

### IF-002 サーバー時刻同期連携

- **連携内容:** 外部エンドポイントと通信して現在サーバー時刻を取得し、ローカル時刻との差分（ServerTimeDiff）を補正する
- **連携元→連携先:** WinAuth → 外部時刻同期サーバー（Google等）
- **タイミング:** 随時 / アカウント登録時および手動または必要に応じたサーバー時刻差分補正要求時
- **方式:** REST API
- **データ形式:** その他
- **認証:** なし
- **想定件数・量:** 同期実行時に1リクエスト
- **エラー時:** 通信タイムアウト時は同期をスキップし、差分が24時間を超える極端な時刻ドリフトは異常値として破棄する
- **関連:** FR-008, NFR-004

#### 項目定義

| 項目名 | 型 | 桁数 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| Date | 文字列 | 未定義 | ○ | HTTPレスポンスヘッダーに含まれるサーバー標準日時 |
| ServerTimeDiff | 数値 | 8 | ○ | 算出されたクライアントとサーバー間の時刻差分ミリ秒（24時間以内の値のみ適用） |

### IF-003 YubiKeyハードウェアトークン連携

- **連携内容:** USB HID経由でYubiKeyにチャレンジデータを送信し、暗号化レスポンスを受領して認証データを保護・復号する
- **連携元→連携先:** WinAuth → YubiKey
- **タイミング:** リアルタイム / マスターキー保護・解除時およびYubiKey設定時のチャレンジ・レスポンス処理契機
- **方式:** その他
- **データ形式:** バイナリ
- **認証:** HMAC-SHA1チャレンジ・レスポンス認証
- **想定件数・量:** パスワード解除または設定保存時に1〜数回
- **エラー時:** ネイティブDLL非存在時はLibraryNotFoundExceptionを捕捉し、クラッシュを防止してソフトウェア認証へフォールバックする
- **関連:** FR-007, NFR-007

#### 項目定義

| 項目名 | 型 | 桁数 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| Challenge | バイナリ | 64 | ○ | YubiKeyに対して送出するチャレンジデータ |
| Response | バイナリ | 20 | ○ | YubiKeyスロットから返却されるレスポンスハッシュデータ |
