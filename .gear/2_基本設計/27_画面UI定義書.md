# 画面UI定義書

WinAuth の各 Windows Forms 画面（`SCR-001`〜`SCR-018`）に配置されている実際の UI コントロール、入力検証仕様、およびイベント動作を定義します。全フォームは `ResourceForm`（`MetroForm` 継承）を基底とし、`MetroStyleManager` / `MetroStyleExtender` による統一デザイン、`LanguageManager` 連携による動的ローカライズ再適用（`ApplyLanguage`）、`UiFontHelper` による高視認性フォント適用（`Yu Gothic UI` / シークレット欄 `Consolas`）、および動的リサイズ時の右上ウィンドウボタン追従制御を備えます。

---

## SCR-001 メイン画面（`WinAuthForm` / `AuthenticatorListBox`）

- **概要**: 認証器一覧の表示・ドラッグ並び替え、OTP コードの表示・保護コピー、起動時ロック解除、各種追加・設定メニュー、およびシステムトレイ常駐を統括するメインフォーム。

### UIコンポーネント・項目定義
| コントロール名 | 型 | 役割・表示仕様 |
| --- | --- | --- |
| `authenticatorList` | `AuthenticatorListBox` | 登録済み認証器を `ClearTypeGridFit` でオーナードロー描画するメインリスト（アイコン、`Yu Gothic UI 10.5pt` 表示名、`Segoe UI 13pt Bold` 5〜8桁 OTP コード、残り時間パイチャートまたは手動更新アイコン）。ドラッグ＆ドロップによる順序変更に対応。 |
| `versionLabel` | `MetroLabel` | 右上ウィンドウボタン直下（`Y=28`）に常時表示されるバージョン表示（例: `v4.1.0`）。ウィンドウ幅変更時に右端へ追従し、左クリックドラッグ時はフォーム移動へ透過連携する。 |
| `loadingPanel` | `MetroPanel` | 非同期設定ファイル読込・PBKDF2 鍵導出中に表示されるローディングパネル。 |
| `passwordPanel` / `passwordField` / `passwordButton` | `MetroPanel` / `MetroTextBox` / `MetroButton` | マスターパスワード保護有効時に表示されるインライン解除パネル。誤入力時は `passwordErrorLabel` に3秒間エラーを表示。 |
| `yubiPanel` / `yubiRetryButton` | `MetroPanel` / `MetroButton` | YubiKey 未挿入・応答エラー時に挿入を促し再試行するインラインパネル（USB着脱 `WM_DEVICECHANGE` でも自動検知）。 |
| `introLabel` | `MetroLabel` | 認証器が 0 件の初期状態で追加手順を案内するガイド表示（左右アンカーにより高DPI・自動サイズ調整時も枠内に折り返し表示）。 |
| `addAuthenticatorButton` / `addAuthenticatorMenu` | `MetroButton` / `ContextMenuStrip` | 下部ツールバーの［Add / 追加］ボタンおよびプロバイダ選択メニュー（汎用認証器 (TOTP/HOTP), Google, Microsoft, Battle.Net, Guild Wars 2, Glyph/Trion, Steam, Okta Verify, Import... / インポート...）。 |
| `optionsButton` / `optionsMenu` | `MetroButton` / `ContextMenuStrip` | 歯車アイコンボタンおよび全体設定メニュー（保護設定、常に手前に表示、タスクトレイ常駐、Windows起動時開始、自動サイズ調整（既定ON）、エクスポート、更新の確認、バージョン情報、**Language (`Japanese` / `English`)**、終了）。 |
| `authenticatorMenu` | `ContextMenuStrip` | 各認証器項目の右クリックメニュー（Show/Copy Code, Protection, Auto Refresh, Copy on New Code, Icon変更, Shortcut Key, Sync Time, Show Secret/Restore/Confirmations, Rename, Delete）。 |
| `notifyIcon` / `notifyMenu` | `NotifyIcon` / `ContextMenuStrip` | システムトレイ常駐アイコンおよびトレイ右クリックメニュー。 |
| `newVersionLink` | `MetroLink` | `WinAuthUpdater` が新バージョンを検出した際に表示される更新確認リンク。 |

### 主要イベント・動作
| トリガー | アクション・システム応答 |
| --- | --- |
| `mainTimer_Tick` (1秒周期) | `AutoRefresh` 有効な TOTP 項目の残り時間インジケーターを更新し、周期境界でコードを再計算する。また遅延保存予約時刻に達していれば `SaveConfig` を実行する。 |
| リスト項目クリック / ダブルクリック | 手動更新モードまたは HOTP 項目では新規コードを算出・一時表示（個別保護時は `SCR-009` 表示）。ダブルクリックまたは［Copy Code］で保護属性付きクリップボードコピーを実行。 |
| インライン名前編集 | ［Rename］選択時にリスト項目上にテキストボックスを表示し、`Enter` で確定・保存する。 |

## SCR-002〜SCR-006 認証器追加・インポート画面群

### SCR-002 汎用認証器追加画面（`AddAuthenticator`）
| コントロール / 項目 | 種別・検証条件 | 説明 |
| --- | --- | --- |
| `nameField` | `MetroTextBox`（必須） | アカウント識別名。`otpauth://` 読込時はラベルから自動補完。 |
| `secretCodeField` | `SecretTextBox`（必須） | Base32 秘密鍵、`otpauth://` URI、または QR コード画像（ファイルパス / URL / Data URI）。無効な Base32 文字はエラー表示。 |
| 時間ベース / カウンターベース切替 | `GroupRadioButton` / Tab | TOTP（周期 `periodField` 既定30秒、HMAC `SHA1`/`SHA256`/`SHA512`、桁数 `6`〜`8`）または HOTP（初期カウンター `counterField`）を選択。 |
| `verifyAuthenticatorButton` / `codeField` | `MetroButton` / `SecretTextBox` | 入力シークレットから `Enroll` と時刻同期を実行し、テスト生成コードと進捗バー（`newAuthenticatorProgress`）をプレビュー表示する。 |

### SCR-003 サービス別 TOTP 追加画面群（`AddGoogle` / `AddMicrosoft` / `AddGuildWars` / `AddOktaVerify`）
- 各サービスの標準アイコン選択、QRコード画像デコード（`ZXing.BarcodeReader`）またはシークレットキー入力、［Verify Authenticator］による 6桁 TOTP プレビュー検証、および確定前の未検証キャンセル警告を備える。

### SCR-004 Battle.net 追加・復元画面（`AddBattleNetAuthenticator`）
- **新規発行タブ**: リージョン選択または GeoIP 自動判定により `BattleNetAuthenticator.Enroll()` を実行し、発行された `Serial`（17文字）と `RestoreCode`（10文字）を画面提示する。
- **リストアタブ**: 既存シリアル番号と10文字リストアコードを入力し、`Restore()` により秘密鍵を復元登録する。

### SCR-005 Steam 追加・インポート画面（`AddSteamAuthenticator`）
- **ログイン・SMS登録タブ**: Steam アカウント名・パスワード、必要に応じた CAPTCHA 画像入力・メール認証コード入力、および携帯電話に送信された SMS アクティベーションコードを入力し、リカバリーコード（`Rxxxxx`）の控え確認を必須とした上で登録を完了する。
- **インポートタブ**: Android 版 `Steamguard-*` ファイルまたは Steam Desktop Authenticator（`.maFile`）を読み込んで登録する。

### SCR-006 Trion 追加・復元画面（`AddTrionAuthenticator`）
- 新規デバイスキー生成（`Enroll`）または Trion アカウント資格情報＋秘密の質問回答による既存キー復元（`Restore`）を行う。

## SCR-007 マスター保護・暗号化設定画面（`ChangePasswordForm`）

- **概要**: `winauth.xml` 全体の `WINAUTH4` 暗号化保護レベルを設定・変更・解除する画面。

| コントロール名 | 型 | バリデーション・動作仕様 |
| --- | --- | --- |
| `passwordCheckbox` / `passwordField` / `verifyField` | `MetroCheckBox` / `MetroTextBox` | チェック時にマスターパスワード入力を有効化。空文字禁止、確認入力との完全一致必須（`PasswordTypes.Explicit`）。 |
| `machineCheckbox` / `userCheckbox` | `MetroCheckBox` | このコンピュータ上でのみ復号可能にする DPAPI `LocalMachine` 保護、および現在ログオン中の Windows ユーザーに限定する `CurrentUser` 保護を設定。 |
| `yubikeyBox` / スロット選択UI | `MetroCheckBox` / Panel | 非同期で `YubiKey.CreateInstance()` を実行しファームウェア・シリアルを表示。Slot 1 または Slot 2 の既存設定利用または新規シード書き込みを行う。 |

## SCR-008〜SCR-010 個別保護・本人確認・PGP鍵入力ダイアログ群

| 画面ID・クラス名 | 主要コントロール | バリデーション・動作仕様 |
| --- | --- | --- |
| **SCR-008** `SetPasswordForm` | `passwordField`, `verifyField`, `removeCheckBox` | 特定認証器単体へのパスワード設定・確認一致検証、またはチェックによる個別保護の解除。 |
| **SCR-009** `UnprotectPasswordForm` | `passwordField`, `okButton` | 個別保護された認証器のコード表示時または暗号化 ZIP インポート時にパスワードを入力（最前面フォーカス制御付き）。 |
| **SCR-010** `GetPasswordForm` / `GetPGPKeyForm` | `passwordField` / `pgpField`, `passphraseField`, `browseButton` | シークレット表示・保護設定変更・エクスポート前の現在のマスターパスワード検証（`Config.IsPassword`）、および `.pgp` 復号用の秘密鍵ファイル指定とパスフレーズ入力。 |

## SCR-011 ショートカットキー・自動入力設定画面（`SetShortcutKeyForm`）

- **概要**: 認証器ごとにグローバルホットキーと発火時の自動操作を設定するダイアログ。

| コントロール名 | 型 | バリデーション・動作仕様 |
| --- | --- | --- |
| `keyCombo` / `shiftToggle` / `ctrlToggle` / `altToggle` | `MetroComboBox` / `MetroToggle` | 仮想キー（`VK_SPACE` 以降または `None`）と修飾キーを選択。確定時に `KeyboardHook.IsHotkeyAvailable` で他アプリとの競合を検証し、使用中ならエラーを表示。 |
| `notifyRadioButton` | `MetroRadioButton` | ホットキー押下時に `SCR-018` トースト通知ウィンドウでコードを表示する（`HotKeyActions.Notify`）。 |
| `pasteRadioButton` | `MetroRadioButton` | ホットキー押下時にコードを保護クリップボードへコピーする（`HotKeyActions.Copy`）。 |
| `injectRadioButton` / `injectTextbox` | `MetroRadioButton` / `MetroTextBox` | 指定したウィンドウタイトル・プロセス名（正規表現 `/pattern` 可）のウィンドウへ自動キー入力する（`HotKeyActions.Inject`）。 |
| `advancedRadioButton` / `advancedTextbox` | `MetroRadioButton` / `MetroTextBox` | `{CODE}`, `{TAB}`, `{ENTER}`, `{WAIT}`, `{COPY}`, `{PASTE}` 等のマクロ構文による高度な自動入力を実行する（`HotKeyActions.Advanced`）。 |

## SCR-012 Steam トレード確認画面（`ShowSteamTradesForm`）

- **概要**: Steam モバイル確認一覧の照会・承認・拒否およびバックグラウンド自動確認設定を行う画面。

| コントロール名 | 型 | 動作仕様 |
| --- | --- | --- |
| ログインパネル (`usernameField`, `passwordField`, `captchaField`) | `MetroPanel` / `MetroTextBox` | セッション未確立時に Steam OAuth ログインを実行する。確立後は確認一覧パネルへ切り替わる。 |
| 保留トレード一覧 (`tradesContainer` / 行アイテム) | スクロールリスト | 取引相手アイコン、アイテム概要、日時を表示し、クリックで `/mobileconf/details/{id}` の詳細を表示、各行の［Accept］/［Reject］で署名付き承認・拒否を実行（二重押下抑止付き）。 |
| ポーリング設定 (`pollCheckbox`, `pollNumeric`, `pollActionCombo`) | `MetroCheckBox` / Numeric / Combo | 指定分数間隔でのバックグラウンド確認チェックと動作（通知のみ / 自動承認等）を `SteamSession` に保存する。 |
| `refreshButton` / `logoutButton` | `MetroButton` | 一覧の手動再取得、および `SteamClient.Logout()` による Web セッション破棄・Cookie クリアを実行する。 |

## SCR-013〜SCR-018 シークレット閲覧・エクスポート・システム情報画面群

| 画面ID・クラス名 | 主要UI要素 | 動作仕様 |
| --- | --- | --- |
| **SCR-013** `ShowSecretKeyForm` / `ShowRestoreCodeForm` / `ShowSteamSecretForm` / `ShowTrionSecretForm` | シークレット表示欄（`SecretTextBox`）、QRコード描画 `PictureBox`（`ZXing.BarcodeWriter`）、シリアル/デバイスID/`SteamData` 表示欄 | 本人確認通過後に秘密鍵（Base32）、再スキャン用 QR コード、Battle.net 10文字リストアコード、Steam リカバリーコードと JSON データ、Trion デバイスIDを閲覧専用で表示する。 |
| **SCR-014** `ExportForm` | `fileField`, `browseButton`, `passwordCheckbox` (`passwordField`/`verifyField`), `pgpCheckbox` (`pgpField`/`pgpBrowseButton`) | 出力形式を排他選択し、平文 `.txt`（`otpauth://` 一覧）、パスワード暗号化 `.zip`（`SharpZipLib`）、または公開鍵暗号化 `.pgp`（`BouncyCastle OpenPGP`）を出力する。 |
| **SCR-015** `AboutForm` | バージョン・著作権ラベル（高さ `64px`）、ライセンス情報、外部リンク、［Diagnostics］ボタン、右上クローズボタン `'r'` | アセンブリバージョンおよび著作権表示（`Copyright © 2013-2026 Colin Mackie / Modified 2026 CTD Networks Co., Ltd.`）と GPLv3 情報を表示。動的リサイズ時に右上制御ボタンがクライアント領域内へ即座に追従する。 |
| **SCR-016** `UpdateCheckForm` | バージョン比較表示（HTML、`Yu Gothic UI` 適用）、自動確認チェックボックス（初期値 OFF）、更新確認間隔コンボボックス | GitHub Releases API から最新版チェック結果を取得・多言語表示し、自動チェック有効化時のみ間隔（毎回〜1か月ごと）を保存する（右上ボタン追従対応）。 |
| **SCR-017** `DiagnosticForm` / `ExceptionForm` | 診断テキスト表示 / 例外スタック表示、［Continue］/［Quit］ボタン | 設定・同期状態の自己診断確認、および未処理例外発生時のエラー記録確認と継続・終了選択を行う。 |
| **SCR-018** `Notification` | アカウント名ラベル、OTPコード表示ラベル、クローズタイマー | タスクトレイ付近に数秒間ポップアップ表示され、クリックすると表示中のコードをクリップボードへコピーして閉じる。 |
