# 画面一覧

WinAuth（`WinAuth.csproj`）に実装されているすべての Windows Forms 画面およびダイアログを以下に定義します。

| 画面ID | 画面名 | フォームクラス名 | 種別 | 画面概要 | 関連機能ID |
| --- | --- | --- | --- | --- | --- |
| SCR-001 | メイン画面 | `WinAuthForm` | メインフォーム | 登録済み認証器の一覧表示（`AuthenticatorListBox`）、OTP自動更新・コピー、起動時ロック解除（`passwordPanel` / `yubiPanel`）、追加メニュー、オプションメニュー、システムトレイ常駐を統括する中心画面。 | FR-001, FR-002, FR-010, FR-011, FR-013, FR-014 |
| SCR-002 | 汎用認証器追加画面 | `AddAuthenticator` | モーダルダイアログ | 標準 RFC 6238（TOTP: SHA1/SHA256/SHA512、任意周期・桁数）および RFC 4226（HOTP: カウンター指定）、QRコード/`otpauth://` URI から汎用認証器を登録する画面。 | FR-001, FR-002, FR-006 |
| SCR-003 | Google / Microsoft / GuildWars / Okta 追加画面群 | `AddGoogleAuthenticator` / `AddMicrosoftAuthenticator` / `AddGuildWarsAuthenticator` / `AddOktaVerifyAuthenticator` | モーダルダイアログ | 各サービス向けのガイド・初期アイコン・QRコード画像読取・Base32シークレット入力・確認コード検証を備えた専用追加画面群。 | FR-001, FR-006 |
| SCR-004 | Battle.net 認証器追加・復元画面 | `AddBattleNetAuthenticator` | モーダルダイアログ | Blizzard サーバーと通信して新規シリアル・秘密鍵を発行（Create）するか、既存シリアルと10文字リストアコードから復元（Restore）する専用登録画面。 | FR-003 |
| SCR-005 | Steam 認証器追加・インポート画面 | `AddSteamAuthenticator` | モーダルダイアログ | Steam アカウントへのログイン・CAPTCHA/メール認証・SMSアクティベーションによる新規登録、または Android `Steamguard-*` / SDA `.maFile` インポートを行う専用画面。 | FR-004 |
| SCR-006 | Trion / Glyph 認証器追加・復元画面 | `AddTrionAuthenticator` | モーダルダイアログ | Trion サーバーと通信して新規デバイスキー・シリアルを生成するか、アカウント認証と秘密の質問（Security Questions）から既存キーを復元する画面。 | FR-006 |
| SCR-007 | マスター保護・暗号化設定画面 | `ChangePasswordForm` | モーダルダイアログ | 設定ファイル全体の保護方式（マスターパスワード、Windows DPAPI［現在PC / 現在ユーザー限定］、YubiKey Slot 1 / Slot 2）を設定・変更・解除する画面。 | FR-007, FR-009 |
| SCR-008 | 個別パスワード設定画面 | `SetPasswordForm` | モーダルダイアログ | 特定の認証器単体に対して個別のパスワード保護を設定・解除する画面。 | FR-008 |
| SCR-009 | 個別ロック解除画面 | `UnprotectPasswordForm` | モーダルダイアログ | 個別パスワード保護された認証器のコード表示・操作時、またはインポート時の保護解除パスワードを入力する画面。 | FR-008, FR-012 |
| SCR-010 | パスワード再確認画面 / PGP鍵入力画面 | `GetPasswordForm` / `GetPGPKeyForm` | モーダルダイアログ | 機密情報（シークレットキー・リストアコード・エクスポート・保護設定変更）へのアクセス前の本人確認パスワード入力、および `.pgp` インポート時の秘密鍵・パスフレーズ入力を行う画面。 | FR-007, FR-008, FR-012 |
| SCR-011 | ショートカットキー・自動入力設定画面 | `SetShortcutKeyForm` | モーダルダイアログ | 認証器ごとのグローバルホットキー（Ctrl/Alt/Shift + キー）と動作（通知表示 / コピー / 対象ウィンドウ自動入力 `Inject` / 高度なスクリプト `Advanced`）を設定する画面。 | FR-011 |
| SCR-012 | Steam トレード確認画面 | `ShowSteamTradesForm` | モーダルダイアログ | Steam ログイン維持、保留中トレード・マーケット出品の一覧表示・詳細確認、個別承認（Accept）/ 拒否（Reject）、およびバックグラウンド自動確認ポーリング設定を行う画面。 | FR-005 |
| SCR-013 | シークレット・復元情報表示画面群 | `ShowSecretKeyForm` / `ShowRestoreCodeForm` / `ShowSteamSecretForm` / `ShowTrionSecretForm` | モーダルダイアログ | 登録済み認証器の Base32 シークレット・`otpauth://` QRコード、Battle.net リストアコード、Steam デバイスID/リカバリーコード/`SteamData`、Trion シリアルを表示する画面群。 | FR-003, FR-004, FR-006, FR-008 |
| SCR-014 | エクスポート画面 | `ExportForm` | モーダルダイアログ | 登録済み認証器群を平文テキスト（`.txt`）、パスワード暗号化 ZIP（`.zip`）、または OpenPGP 公開鍵暗号化（`.pgp`）形式でファイル出力する画面。 | FR-012 |
| SCR-015 | バージョン情報画面 | `AboutForm` | モーダルダイアログ | アプリケーションバージョン（v4.0）、著作権・クレジット、GPL ライセンス表記を表示し、診断画面（`DiagnosticForm`）への導線を提供する画面。 | FR-014 |
| SCR-016 | アップデート確認画面 | `UpdateCheckForm` | モーダルダイアログ | 最新リリース情報の確認結果・変更履歴の表示、および自動更新チェック周期の設定を行う画面。 | FR-014 |
| SCR-017 | 診断情報画面 / 例外レポート画面 | `DiagnosticForm` / `ExceptionForm` | モーダルダイアログ | 登録状態や通信・環境診断情報の確認（`DiagnosticForm`）、および未処理例外発生時のエラー詳細表示・継続/終了選択（`ExceptionForm`）を行う画面。 | FR-014, NFR-005 |
| SCR-018 | トースト通知ウィンドウ | `Notification` | ポップアップフォーム | システムトレイ操作時やホットキー「Notify」アクション実行時に、画面右下へ OTP コードを一定時間ポップアップ通知しクリックでコピーできる軽量ウィンドウ。 | FR-011, FR-013 |
